# Easy VLESS 0.5.1-r1: TR3000 release-candidate validation

**Status of every step in this file: UNVERIFIED.** Nothing here has run on the real router yet. Run the blocks in order on the Cudy TR3000 (OpenWrt 24.10.3, mediatek/filogic) as root over SSH, then paste the output back. Each block is safe to paste as a whole.

IPKs must come from the GitHub Actions artifact (the real OpenWrt 24.10.3 mediatek/filogic SDK build). They must not come from the offline harness build. Copy them to `/tmp/ev/` on the router first, for example `scp -O *.ipk root@192.168.1.1:/tmp/ev/`.

```sh
mkdir -p /root/ev-backup && cp /etc/config/easy_vless /root/ev-backup/easy_vless.$(date +%Y%m%d-%H%M%S)
ls -l /root/ev-backup/
opkg list-installed | grep -E 'easy-vless|sing-box|nft|tproxy|socket|dnsmasq'

```

## 4. Traffic and resource routing

Before this block, in LuCI:
1. Add the prepared rules RUSSIA and PROXY.
2. On Main, set RUSSIA to Direct and PROXY to your VLESS server.
3. Save & Start.

Set the log level to `info` temporarily: Settings, Advanced, Log level.

```sh
free -h; top -bn1 | grep '[s]ing-box'
curl -s -m 10 -o /dev/null -w "ya.ru %{http_code} %{time_total}\n" https://ya.ru
curl -s -m 10 -o /dev/null -w "google.com %{http_code} %{time_total}\n" https://www.google.com
nslookup ya.ru 127.0.0.1; nslookup google.com 127.0.0.1
L=$(ls /tmp/etc/easy_vless/acl/*/*.log 2>/dev/null | head -1); echo "log: $L"
grep -E 'ya\.ru|google\.com' "$L" | grep -E 'outbound' | tail -6
```

Expected: `ya.ru` goes out through `outbound/direct`, and `google.com` goes out through the VLESS outbound. The PROXY list contains `regexp:\.com$`.

Run the same checks from a LAN client, for example a PC behind the router: `curl https://ya.ru` and `curl https://www.google.com`.
