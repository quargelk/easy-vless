# Easy VLESS v1.3.0-rc.1

Кандидат на выпуск Easy VLESS 1.3.0. Версия пакетов `1.3.0-r1`,
версия отдельного ядра `sing-box-lx 1.14.4-lx.35`
(`1.14.4_p35-r1` в метаданных OpenWrt). Пакеты рассчитаны на
`x86_64` и `aarch64_cortex-a53`.
OpenWrt 24.10.x использует IPK, OpenWrt 25.12.x использует APK.

- Установка и обновление со штатным LuCI, с сохранением UCI из 1.2.0.
- Пакет ядра владеет `/usr/bin/sing-box-lx`. Путь `/usr/bin/sing-box`
  продолжает обслуживать прежний пакет.
- Установщик сверяет версию прошивки, ABI, ресурсы, зависимости и комплект
  отката. Для APK необходим заранее проверенный ключ выпуска. Инструкция
  по проверке манифеста, запуску `--check` и восстановлению входит в
  `INSTALL-RC.md`. Получите отпечаток ключа у сопровождающего через уже
  доверенный канал перед добавлением PEM в хранилище OpenWrt.
- Минимум 128 МБ flash и 256 МБ RAM. Дополнительно требуется свободное
  место под пакеты, загрузку и восстановление. Обновлённый официальный
  репозиторий может убрать прежнюю версию `dnsmasq`, необходимую для отката.
- Испытания перезагрузки, LAN, DHCP и маршрутизации с Easy VLESS на TR3000
  входят в критерии стабильного 1.3.0.
