# Сборка и установка

Используются официальные SDK OpenWrt 24.10.3 и 25.12.6 для
`x86/64` и `mediatek/filogic`. Пакеты ядра привязаны к
`x86_64` и `aarch64_cortex-a53` соответственно. Для другого
ARM64 ABI нужен соответствующий SDK и отдельная проверка пакетов.
Сборки для ARMv7, MIPS, i386 и RISC-V в этот комплект не входят.

## Сборка

1. Откройте каталог целевой платформы под
   [downloads.openwrt.org/releases](https://downloads.openwrt.org/releases/).
   Скачайте SDK и сверьте файл с официальным `sha256sums`.
2. Распакуйте SDK. Нужны Git, Go с поддержкой выбора toolchain,
   Python 3, GNU Make, компилятор хоста и стандартные инструменты SDK.
3. Запустите из корня Easy VLESS.

```sh
bash scripts/sdk-build.sh --feeds /path/to/sdk ./dist/lx-build
```

SDK собирает IPK через `package.mk` и `ipkg-build`, APK через
`package.mk` и `apk mkpkg`. Go запускается с
`CGO_ENABLED=0`, `-trimpath`, `-mod=readonly`, `-buildvcs=false`.
Go проверяет зависимости по закреплённому `go.sum` и своей БД
контрольных сумм. Коммит и build tags заданы в `scripts/build-core.sh`.
Ядро можно собрать отдельно.

```sh
bash scripts/build-core.sh x86_64 ./dist/core/sing-box-lx
bash scripts/build-core.sh aarch64_cortex-a53 ./dist/core/sing-box-lx-arm64
```

В IPK архитектура записана в имени файла и в `control`. В APK
имя публикуемого файла дополнено ABI, а внутреннее имя пакета
остаётся `sing-box-lx`. Приложения остаются `all` в IPK и
`noarch` в APK. Сборка CI формирует независимые наборы для
каждой пары формата и ABI. Подпись и контрольные суммы выпускаются
из окончательных артефактов.

## Подписи и установка

На 25.12 установщик по умолчанию запускает `apk verify` с ключами
роутера. Если есть ключ выпуска, задайте `EV_APK_SIGNING_KEY`
с абсолютным путём к приватному PEM при запуске SDK-сборки.
Установщик сам не записывает публичные ключи. Администратор сверяет
отпечаток и добавляет публичный ключ проекта отдельной процедурой.
Для тестового комплекта предусмотрен явный параметр
`--allow-unsigned` совместно с `--local`. Пакеты с таким
исключением ставятся из проверенных локальных файлов без сетевых
репозиториев. Зависимости, загружаемые из OpenWrt, разрешаются
отдельно с проверкой подписи официальных индексов.

IPK из локального набора сверяются с `SHA256SUMS`. Список сумм,
полученный вместе с файлами, подтверждает их целостность.
Подлинность набора зависит от источника файла сумм. Для выпуска
рекомендуется подписывать манифест отдельным доверенным ключом.
Файлы одного набора можно проверить на компьютере.

```sh
cd /path/to/bundle
sha256sum -c SHA256SUMS
sh install.sh --check --local "$PWD"
sh install.sh --local "$PWD" --no-start
```

Для замены dnsmasq требуется `--replace-dnsmasq` или интерактивное
подтверждение. Установщик сверяет исходную версию dnsmasq с копией
для отката. Если стабильный feed уже заменил эту версию, укажите
`--dnsmasq-rollback-dir` с сохранённым официальным индексом
(`packages.adb` для APK или `Packages` и `Packages.sig` для IPK)
и точным прежним пакетом. При отсутствии проверяемой копии
установщик оставляет системный DNS в исходном состоянии.
Предварительная проверка учитывает RAM, размер носителя,
доступное место в overlay и tmpfs, версии и архитектуру файлов.
TLS и пакетный менеджер должны работать до сетевой установки.

## Миграция и офлайн-режим

При обновлении с 1.2.0 сохраните комплект ранее установленной
версии и его `SHA256SUMS`. На офлайн-роутере необходимые системные
зависимости и dnsmasq с nftset должны быть заранее установлены.

```sh
sh /path/to/bundle/install.sh --check --offline --local /path/to/bundle \
  --rollback-dir /path/to/previous
sh /path/to/bundle/install.sh --offline --local /path/to/bundle \
  --rollback-dir /path/to/previous --no-start
```

Установщик сохраняет UCI и подготавливает старые пакеты до изменения
установки. Старое ядро остаётся доступно для потребителей и отката.
После проверки нового запуска убрать прежнее ядро можно штатным
менеджером пакетов, если у него отсутствуют зависимости и потребители.
Для удаления Easy VLESS остановите службу и удалите
`luci-app-easy-vless easy-vless-sing-box easy-vless`; затем при
необходимости удалите `sing-box-lx` и опциональные компоненты.
Системный dnsmasq сохраняется. Перед удалением сохраните UCI и резервные
копии отдельно от файлов, управляемых пакетом.


## Проверка комплектов

`tests/core-package-check.sh` проверяет метаданные, ABI, ELF,
состав файлов ядра и SHA256. На x86_64 он также запускает локальный
HTTPS-тест. `tests/apk-package-check.sh` проверяет пакеты приложения,
точные зависимости, режимы файлов и скрипты сопровождения.

`tests/ci/lx-runtime-tests.sh` запускается в одноразовых OpenWrt
rootfs 24.10.3 и 25.12.6. В прогоне проверяются установка, UCI и rpcd,
генерация конфигурации, подписки, офлайн-переустановка и удаление.
Для миграции задаётся `EV_OLD_BUNDLE` с комплектом 1.2.0.
Для изолированной проверки nftables задаётся `EV_CI_NET_ADMIN=1`
и контейнеру предоставляется NET_ADMIN в его сетевом namespace.
Полностью загруженная OpenWrt с LAN-клиентами нужна для испытаний
procd, DHCP и перехвата клиентского трафика на реальном интерфейсе.
