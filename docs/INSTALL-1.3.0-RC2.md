# Easy VLESS v1.3.0-rc.2

Скачайте `install.sh` с [предварительного выпуска](https://github.com/quargelk/easy-vless/releases/tag/v1.3.0-rc.2)
по HTTPS и запустите от root. Установщик сам сверяет закреплённый манифест,
выбирает пакеты и до изменения системы собирает комплект восстановления.

```sh
sh install.sh --check
sh install.sh
```

Если GitHub недоступен с роутера, скачайте на ПК `install-from-pc.sh`
из того же выпуска. SSH должен доверять заранее проверенному ключу роутера.

```sh
sh install-from-pc.sh root@192.168.10.1 --check
sh install-from-pc.sh root@192.168.10.1
```

Оба скрипта принимают `--base-url https://…`. Скрипт на ПК проверяет
подпись манифеста с закреплённым отпечатком и передаёт только нужные файлы.
Роутеру остаётся доступ к официальным фидам OpenWrt.

Перед заменой DNS потребуется подтверждение. Откат использует приватный
каталог в `/tmp`, контрольные суммы и автономный процесс на случай обрыва.
Во время транзакции нужна работающая система. При перезагрузке содержимое
`/tmp` теряется. Если точной доверенной копии заменяемого пакета нет,
установка остановится до изменения пакетов. Для исходного TR3000 с
OpenWrt 25.12.6 и `dnsmasq 2.93-r1` такая копия входит в выпуск.
