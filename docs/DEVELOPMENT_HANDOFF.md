# Передача разработки Easy VLESS 1.3.0-r1

Срез подготовлен 22 ноября 2026 года в ветке `feature/sing-box-lx-integration`.
Это локальная разработка: изменения не опубликованы, TR3000 не изменялся.

## Состояние

Easy VLESS 1.3.0-r1 использует пакетный sing-box-lx 1.14.4-lx.35
(сборка upstream `f1bac271853eaf13398ce1030c948aebc3aed2e1`). Существующая
интеграция UCI, генератор конфигурации, управление службой, импорт узлов,
подписки, обновление и backend LuCI сохранены и адаптированы. Поддержаны
TCP/TLS, REALITY/uTLS, Vision, WS, gRPC, HTTPUpgrade, Trojan, DNS/FakeIP,
routing и URL Test; XHTTP имеет базовую схему и проверку на локальном стенде.
Необрабатываемые параметры отклоняются явно. Внешний редизайн LuCI не начинался.

Пакет ядра устанавливает `/usr/bin/sing-box-lx`, не перезаписывая системный
`sing-box`. Сборки выполнены официальными SDK OpenWrt 24.10.3/IPK и
25.12.6/APK для `x86_64` и `aarch64_cortex-a53` (mediatek/filogic).
Другие ABI пока не проверены. Установленные размеры ELF: 43,040,894 байта
(x86_64), 40,108,158 байт (ARM64); архивы ядра примерно 13.8–15.4 MB.
Это не доказывает пригодность любого устройства с flash 128 MB: overlay
и зависимости нужно оценивать отдельно. Подробности описаны в
[HARDWARE_REQUIREMENTS.md](HARDWARE_REQUIREMENTS.md).

## Проверки и доказательства

В этой сессии `bash tests/static-checks.sh` прошёл полностью: проверены
shell/Lua/JS синтаксис, JSON, переводы, ресурсы, diff whitespace и быстрые
регрессии; включая Trojan, backup/import, диагностику, shell safety и update.
Четыре файла `SHA256SUMS` в комплектах IPK/APK повторно проверены успешно.
Повторный запуск `core-package-check.sh` для x86 остановился на попытке
создать локальный HTTPS listener: sandbox вернул `PermissionError` для bind.
Вследствие этого в этой сессии дополнительные `core-package-check` и
`apk-package-check` не завершены; не считать их повторно подтверждёнными.
Физический TR3000 ранее проверен только временным loopback core и SSH-forwarded
SOCKS5: 6/6 внешних HTTPS-запросов успешны, сертификат проверен. Измерения:
RSS ядра в простое около 33 MiB, после HTTPS около 35 MiB; запуск около секунды.
Установленные пакеты, постоянные настройки, DNS, firewall и маршрутизация
роутера не менялись.

Ранее также проходили локальные транзакционные тесты в изолированных OpenWrt
rootfs (IPK/APK), имитация ограниченной памяти/overlay, rollback тестовой
установки, локальные HTTPS тесты VLESS/Trojan/транспортов и XHTTP TLS в трёх
режимах на Xray. Это результаты предыдущего этапа, не повторённые сейчас.
Не подтверждены: полная procd-среда на устройстве, LAN DHCP/DNS и клиентский
перехват, реальная нагрузка и flash на нескольких архитектурах, IPv6-трафик,
XHTTP через REALITY/промежуточный HTTP-сервер. Для перечня см.
[документ испытаний TR3000](TR3000_LIVE_TRIAL.md).

## Комплекты сборок

В репозитории локально присутствуют, Git их игнорирует:

| Комплект | Путь |
| --- | --- |
| OpenWrt 24.10 IPK, ARM64 filogic | `dist/sing-box-lx-integration/ipk-aarch64_cortex-a53/` |
| OpenWrt 24.10 IPK, x86_64 | `dist/sing-box-lx-integration/ipk-x86_64/` |
| OpenWrt 25.12 APK, ARM64 filogic | `dist/sing-box-lx-integration/apk-aarch64_cortex-a53/` |
| OpenWrt 25.12 APK, x86_64 | `dist/sing-box-lx-integration/apk-x86_64/` |

В каждом каталоге находится `SHA256SUMS`, все пакеты приложения, ядро и
`install.sh`. Проверка выполняется из каждого каталога командой
`sha256sum -c SHA256SUMS`. Эти суммы подтверждают целостность относительно
манифеста, но сами по себе не являются подписью источника.

4. На роутере проверить watchdog и состояние `armed` из новой SSH-сессии до

ещё не выполнены.

## Воспроизведение сборки

Исходники закрепляют версию и commit ядра в `scripts/build-core.sh`.
Для нового комплекта использовать проверенный официальный SDK и команды из
[BUILD_AND_PACKAGING.md](BUILD_AND_PACKAGING.md). Текущие локальные SDK и Go
кеши находятся в `/tmp/easy-lx-work/` и не входят в резервные архивы; их можно
удалить после сохранения комплектов `dist/`. Перед продолжением проверить:

```sh
git status --short --branch
bash tests/static-checks.sh
for f in dist/sing-box-lx-integration/*/SHA256SUMS; do
	(cd "${f%/*}" && sha256sum -c SHA256SUMS) || exit 1
done
```

Ветка: `feature/sing-box-lx-integration`. Коммиты и абсолютные пути созданных
архивов зафиксированы в итоговом сообщении сессии. Push, публикация релиза,
новые сборки и live trial в рамках подготовки handoff не выполнялись.
