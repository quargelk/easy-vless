# Компоненты выпуска и исходный код

| Компонент | Происхождение и лицензия |
| --- | --- |
| Easy VLESS, LuCI и скрипты выпуска | Репозиторий [quargelk/easy-vless](https://github.com/quargelk/easy-vless), GPL-3.0-only. Исходники выпуска доступны по тегу `v1.3.0-rc.1`. |
| sing-box-lx 1.14.4-lx.35 | [Leadaxe/sing-box-lx](https://github.com/Leadaxe/sing-box-lx/tree/f1bac271853eaf13398ce1030c948aebc3aed2e1), коммит `f1bac271853eaf13398ce1030c948aebc3aed2e1`. Текст лицензии ядра указывает GPL-3.0-or-later и содержит отдельное замечание об использовании названия. |
| Библиотеки Go и четыре подмодуля ядра | Версии зафиксированы в исходниках ядра. Архив исходников содержит версии из gitlink, vendored зависимости, их лицензионные уведомления и рецепт сборки Easy VLESS. |
| OpenWrt, системные зависимости, Xray и GeoData | Пакетный менеджер получает зависимости из репозиториев OpenWrt. Опциональные обвязки Easy VLESS не копируют бинарник Xray или пакеты геоданных в комплект RC. |

Выпуск распространяет ядро отдельным пакетом `sing-box-lx`.
Исходники для двух сборок ядра входят в собственный архив
`sing-box-lx-1.14.4-lx.35-source.tar.gz`. Рецепт
`easy-vless-build-core.sh` в архиве фиксирует Go 1.26.10,
набор тегов и флаги линковки. `vendor/` позволяет собрать
зависимости без сети с `-mod=vendor` из корня распакованных
исходников. Для ARM64 используется `GOARCH=arm64 GOARM64=v8.0`,
для x86-64 используется `GOARCH=amd64 GOAMD64=v1`, для обеих
сборок используются `GOOS=linux CGO_ENABLED=0`.
